# VKall — Модификация ВКонтакте (VK Android Mod)

VKall — открытый проект модификации официального Android-клиента ВКонтакте. В репозитории содержатся только патчи модифицированного Smali-кода и автоматизированный скрипт самостоятельной сборки.

---

## 🛠️ Как собрать APK самостоятельно из исходников

Для самостоятельной сборки модифицированного приложения вам понадобятся:
- **Linux / macOS / Windows (WSL / Bash)**
- **Java (JDK 11 или новее)**
- **Python 3**

### Инструкция по сборке в 1 клик:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/r4r1ty-tech/VKall.git
   cd VKall
   ```

2. Запустите автоматический скрипт сборки:
   ```bash
   ./build.sh
   ```

Скрипт автоматически:
- Загрузит официальный APK ВКонтакте (версии `8.188.1`).
- Загрузит необходимые инструменты распаковки (**APKTool**, **uber-apk-signer**).
- Дизассемблирует APK в Smali-байткод.
- Наложит все патчи и модификации из папки `modified_smali/`.
- Скомпилирует, выровняет (`zipalign`) и подпишет итоговый APK файл.

Готовый к установке файл будет находиться по адресу:
📂 `build/VK_unsigned-aligned-signed.apk`

---

## 📁 Структура репозитория

- `modified_smali/` — Только модифицированные Smali-файлы нашей разработки.
- `build.sh` — Автоматический скрипт полной распаковки, патчинга и сборки APK.
- `.gitignore` — Исключает оригинальные тяжелые бинарники (`assets/`, `tools/`, `smali_src/`), сохраняя репозиторий лёгким.
