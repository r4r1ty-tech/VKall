# VKall

> Android-модификация клиента ВКонтакте с открытыми патчами и воспроизводимой сборкой.

VKall хранит только измененные части проекта (`Smali`, ресурсы и native-патчи) и скрипт сборки, который автоматически берет базовый APK, применяет модификации и собирает готовый установочный файл.

---

## ✨ Что есть в проекте

- ✅ Открытый набор патчей в `modified_smali/`
- ✅ Автосборка APK одной командой через `build.sh`
- ✅ Версионирование релизов (`versionName` / `versionCode`) при сборке
- ✅ GitHub Actions пайплайн для теговых релизов (`v*`) и ручного запуска
- ✅ Публикация релизов с прикрепленным APK

---

## 🚀 Быстрый старт

### Требования

- Linux / macOS / Windows (WSL + Bash)
- Java 17+ (рекомендуется; в CI используется Java 17)
- Python 3

### Сборка

```bash
git clone https://github.com/r4r1ty-tech/VKall.git
cd VKall
chmod +x ./build.sh
./build.sh
```

Скрипт автоматически:

1. Скачивает базовый APK ВК `8.188.1` (если его нет в `assets/`)
2. Скачивает `apktool` и `uber-apk-signer` (если их нет в `tools/`)
3. Декомпилирует APK в `smali_src/`
4. Применяет все патчи из `modified_smali/`
5. Обновляет `versionName`/`versionCode` в `apktool.yml`
6. Собирает, выравнивает и подписывает APK

Готовый файл:

`build/VKall-<version>.apk`

---

## 🏷️ Релизы

- Автоматический релиз запускается:
  - по тегу `v*` (например, `v0.0.1`)
  - вручную через `workflow_dispatch`
- Workflow: `.github/workflows/release.yml`
- В релиз прикладывается APK формата `VKall-<version>.apk`

## 📁 Структура репозитория

- `modified_smali/` — модифицированные smali/native/res патчи
- `build.sh` — полный цикл сборки, подписи и версионирования APK
